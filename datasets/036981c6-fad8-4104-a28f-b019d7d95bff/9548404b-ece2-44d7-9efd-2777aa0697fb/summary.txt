This paper presents the Numerical Electromagnetic Code (NEC) - Basic Scattering Code, a user-oriented computer code for analyzing the far-field patterns of antennas in the presence of perfectly conducting metal structures at UHF and above. The code uses the Geometrical Theory of Diffraction (GTD) to simulate complex structures, including flat plates, infinite ground planes, and finite elliptic cylinders. The code is designed to be efficient and accurate, with a focus on high-frequency analysis.
